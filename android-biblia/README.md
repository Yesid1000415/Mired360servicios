# Biblia IPUIC para Android

Versión de prueba con Reina-Valera 1909 completa incluida, búsqueda, notas y favoritos locales.

La compilación GitHub Actions genera Biblia-IPUIC-Prueba.apk y su SHA-256. Instalar únicamente desde el artefacto de este repositorio.

La APK está firmada con una clave de depuración. Antes de distribuir una versión definitiva, configurar y respaldar una clave privada de firma; las compilaciones de prueba pueden requerir desinstalar la anterior (se perderían notas locales, que deben exportarse antes).

El texto de la app se copia de biblia.html al compilar. No necesita conexión para la lectura. No incluye RVR1960. Los cambios futuros en biblia.html generan otra APK.
