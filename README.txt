MIRED360SERVICIOS WEB V13 — ANALÍTICA COMERCIAL

Incluye:
- Captura de parámetros UTM: utm_source, utm_medium, utm_campaign, utm_content.
- Captura de asesor mediante ?asesor=NOMBRE.
- Seguimiento de clics en categorías y WhatsApp.
- Seguimiento de secciones vistas.
- El origen del visitante se agrega automáticamente al mensaje de WhatsApp.
- Integración preparada para Google Analytics 4.
- Archivo nuevo: analytics.js.

PARA ACTIVAR ESTADÍSTICAS CENTRALIZADAS EN GOOGLE ANALYTICS 4:
1. Crear una propiedad web en Google Analytics.
2. Copiar el ID de medición (formato G-XXXXXXXXXX).
3. Abrir index.html.
4. Buscar ga4MeasurementId: ""
5. Pegar el ID entre las comillas.
6. Guardar y volver a subir index.html.

Mientras no se configure GA4, el seguimiento de origen hacia WhatsApp y los enlaces de campaña ya funciona.
